# 🌱 Projeto Agrinho 2026 - Portal e Quiz do Agro

## 📋 Descrição do Projeto
Este projeto foi desenvolvido para o Concurso Agrinho 2026 em parceria com a Alura. Trata-se de uma aplicação Web interativa focada no tema **"Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente"**, contendo uma página informativa e um Quiz dinâmico para testar os conhecimentos adquiridos sobre a evolução e sustentabilidade no agronegócio.

## 🚀 Funcionalidades
- **Portal de Conteúdo:** Página inicial responsiva com informações sobre a importância do agro no cotidiano.
- **Quiz Interativo:** Questionário interativo desenvolvido em JavaScript focado em sustentabilidade e tecnologia no campo.
- **Interface Intuitiva:** Design responsivo e acessível adaptado para estudantes e comunidade escolar.
